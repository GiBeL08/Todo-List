# Быстрый старт с XAMPP

## Шаг 1: Переместите проект в XAMPP

Скопируйте всю папку `Todo_List_задание` в папку htdocs:

```
C:\xampp\htdocs\Todo_List_задание
```

**Или переименуйте для удобства:**
```
C:\xampp\htdocs\todo
```

## Шаг 2: Запустите XAMPP

1. Откройте **XAMPP Control Panel**
2. Нажмите **Start** напротив **Apache**
3. Нажмите **Start** напротив **MySQL**
4. Дождитесь, пока оба сервиса запустятся (зеленый индикатор)

## Шаг 3: Откройте проект в браузере

Откройте в браузере:
```
http://localhost/Todo_List_задание
```

или если переименовали:
```
http://localhost/todo
```

## Шаг 4: Откройте проект в VS Code

1. Откройте VS Code
2. File → Open Folder
3. Выберите папку: `C:\xampp\htdocs\Todo_List_задание`
4. Начните редактировать файлы

## Готово! 

База данных и таблица создадутся автоматически при первом открытии проекта.

## Проверка работы

### Проверка подключения к БД:
```
http://localhost/Todo_List_задание/test_db.php
```

### Главная страница:
```
http://localhost/Todo_List_задание/index.php
```

или просто:
```
http://localhost/Todo_List_задание
```

---

## Важно!

- **Не запускайте** `php -S localhost:8000` - используйте Apache из XAMPP
- **Убедитесь**, что Apache и MySQL запущены в XAMPP Control Panel
- Все изменения в VS Code сразу видны в браузере (просто обновите страницу)

---

## Если что-то не работает

1. Проверьте, что Apache и MySQL запущены в XAMPP
2. Проверьте путь в браузере (должен быть `http://localhost/Todo_List_задание`)
3. Откройте `test_db.php` для диагностики проблем
