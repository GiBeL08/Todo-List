# Todo List - Список задач

Простое приложение для управления задачами на PHP.

## Что умеет

- Добавлять задачи
- Редактировать задачи
- Удалять задачи
- Смотреть список задач
- Менять статус задачи (В процессе / Выполнено)
- Просматривать отдельную задачу

## Как запустить

1. Установи XAMPP
2. Скопируй папку проекта в C:\xampp\htdocs\Todo_List_задание
3. Запусти XAMPP Control Panel
4. Нажми Start напротив Apache
5. Нажми Start напротив MySQL
6. Открой в браузере: http://localhost/Todo_List_задание

База данных создастся сама при первом запуске.

Подробнее смотри файл КАК_ЗАПУСТИТЬ.txt

## Структура проекта

- config/database.php - настройки базы данных
- index.php - главная страница
- add.php - добавление задачи
- edit.php - редактирование задачи
- view.php - просмотр задачи
- actions/ - обработчики действий
- assets/css/style.css - стили

## Использование

Открой главную страницу, добавь задачу, редактируй или удаляй её.
