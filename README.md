# Todo List - Система управления задачами

Приложение для управления задачами с использованием PHP, PDO и MySQL.

## Возможности

- Добавление задач с названием, описанием и статусом
- Редактирование существующих задач
- Удаление задач
- Просмотр списка всех задач
- Статусы задач: "В процессе" / "Выполнено"
- Пагинация для больших списков задач
- Быстрое переключение статуса задач

## Используемые технологии

- **PHP** - серверный язык программирования
- **PDO** - расширение PHP для работы с базами данных
- **Prepared Statements** - защита от SQL-инъекций
- **MySQL** - система управления базами данных
- **HTML/CSS** - разметка и стилизация

## Установка и настройка

### Требования

- PHP 7.4 или выше
- MySQL 5.7 или выше
- Веб-сервер (Apache, Nginx или встроенный сервер PHP)

### Шаги установки

1. **Скачайте проект**

2. **Настройте базу данных**

   Откройте файл `config/database.php` и измените параметры подключения:
   ```php
   define('DB_HOST', 'localhost');  // Хост базы данных
   define('DB_NAME', 'todo_list');  // Имя базы данных
   define('DB_USER', 'root');       // Пользователь базы данных
   define('DB_PASS', '');           // Пароль базы данных
   ```

3. **Запустите приложение**

   База данных и таблица будут созданы автоматически при первом запуске.

   **Вариант А: Использование XAMPP (Рекомендуется)**
   
   1. Переместите проект в `C:\xampp\htdocs\Todo_List_задание`
   2. Запустите Apache и MySQL в XAMPP Control Panel
   3. Откройте в браузере: `http://localhost/Todo_List_задание`
   
   Подробная инструкция: см. файл `QUICK_START_XAMPP.md`

   **Вариант Б: Встроенный сервер PHP**
   
   ```bash
   php -S localhost:8000
   ```
   
   Затем откройте в браузере: `http://localhost:8000`

## Безопасность

- Использование **Prepared Statements** для всех SQL-запросов
- Защита от SQL-инъекций через параметризованные запросы
- Экранирование вывода через `htmlspecialchars()`
- Валидация входных данных

## Структура таблицы tasks

```sql
CREATE TABLE tasks (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    status ENUM('В процессе', 'Выполнено') DEFAULT 'В процессе',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## Особенности реализации

### CRUD операции

- **Create (Создание)**: `add.php` - добавление новых задач
- **Read (Чтение)**: `index.php` - просмотр списка задач
- **Update (Обновление)**: `edit.php` - редактирование задач
- **Delete (Удаление)**: `actions/delete.php` - удаление задач

### Использование PDO

Все запросы к базе данных выполняются через PDO с использованием подготовленных запросов:

```php
// Пример создания
$stmt = $pdo->prepare("INSERT INTO tasks (title, description, status) VALUES (?, ?, ?)");
$stmt->execute([$title, $description, $status]);

// Пример чтения
$stmt = $pdo->prepare("SELECT * FROM tasks ORDER BY created_at DESC LIMIT ? OFFSET ?");
$stmt->bindValue(1, $tasksPerPage, PDO::PARAM_INT);
$stmt->bindValue(2, $offset, PDO::PARAM_INT);
$stmt->execute();
$tasks = $stmt->fetchAll();

// Пример обновления
$stmt = $pdo->prepare("UPDATE tasks SET title = ?, description = ?, status = ? WHERE id = ?");
$stmt->execute([$title, $description, $status, $id]);

// Пример удаления
$stmt = $pdo->prepare("DELETE FROM tasks WHERE id = ?");
$stmt->execute([$id]);
```

## Использование

1. Откройте главную страницу в браузере
2. Нажмите "Добавить задачу" для создания новой задачи
3. Заполните форму и сохраните
4. Используйте кнопки "Редактировать" и "Удалить" для управления задачами
5. Изменяйте статус задачи на "Выполнено" для отметки завершенных задач
6. Используйте пагинацию для навигации между страницами
